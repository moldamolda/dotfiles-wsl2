# Contributing

Thanks for taking an interest in these dotfiles. This repo is public so you can read it, learn from it, and fork it freely, but it is my personal WSL2 setup and does not accept pull requests or feature requests. If you want to adapt something, please fork the repo (or use it as a template) and make it yours. If you found a bug, please open a bug report issue instead of sending a patch. Pull requests are auto-closed here so the repo can stay personal and predictable.

## Bugs

Bug reports are welcome through GitHub Issues only. Please include:

- What happened.
- What you expected to happen.
- Steps to reproduce the problem.
- Your environment: WSL version (`wsl -l -v` from PowerShell), Linux distro/version, and any relevant Nix or home-manager generation details.

## Feature Ideas

Feature requests are not accepted in this repo. If an idea would make these dotfiles better for you, please fork the repo (or generate your own copy from the template) and shape it around your own setup.

## Pull Requests

Please do not open pull requests against this repo. They are auto-closed, including bug-fix PRs. For bugs, open an issue instead so the problem can be understood in the context of this personal setup.

## Credit

This repo is a WSL2/Linux port of Kun Chen's original nix-darwin + Home Manager dotfiles. If your question or bug is about the macOS-specific parts (nix-darwin, Homebrew system integration), it likely belongs in his repo, not this one.
